# Confectionery Bot

Telegram-бот для приёма заказов в кондитерской.

## Стек
- Python 3.15+
- aiogram 3
- PostgreSQL (SQLAlchemy 2.0 async + asyncpg)
- APScheduler (напоминания)
- Docker Compose (локальная инфраструктура)

Инструкция появится по мере готовности MVP.
